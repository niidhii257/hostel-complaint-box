# Hostel Complaint Box

## Project Description
Hostel Complaint Box is an individual web development project designed to help hostel students submit complaints regarding hostel facilities and track their complaint status.

## Project Purpose
The purpose of this project is to make hostel complaint management more organized and accessible for students.

Wireframe / Design Phase
